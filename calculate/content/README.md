# 乘数组合计算器

一个用于找出符合特定条件的乘数组合的计算工具。

## 功能描述

该程序可以找出所有符合以下条件的乘数组合：
1. 一个一位小数(A)乘以一个两位小数(B)等于目标数字
2. 一位小数(A)的整数部分不为0 (A >= 1.0)
3. 两位小数(B)的整数部分为1-2位 (0 < B < 100.00)

## 使用方法

### 直接运行源代码
```bash
python calculate.py
```

### 打包成可执行文件

1. 运行自动打包脚本：
```bash
python build_exe.py
```

2. 或者手动使用PyInstaller：
```bash
# 安装PyInstaller
pip install pyinstaller

# 打包程序
pyinstaller --onefile --windowed --name "乘数组合计算器" calculate.py
```

### 在其他计算机上使用

1. 将打包好的 `乘数组合计算器.exe` 文件复制到目标计算机
2. 双击运行即可，无需安装Python环境

## 界面说明

程序启动后会显示一个图形界面，包含：
- 输入框：输入要计算的总金额
- 计算按钮：开始计算
- 结果区域：显示所有符合条件的乘数组合

## 注意事项

1. 输入的金额必须是两位小数格式（例如：123.45）
2. 程序最多显示前200组结果
3. 如果结果超过200组，会提示剩余未显示的数量

## 错误处理

程序会自动处理以下错误情况：
- 输入格式错误
- 输入非数字字符
- 输入负数或零
- 小数位数不正确

## 技术细节

程序使用Python的`decimal`模块进行精确的小数计算，避免浮点数精度问题。通过因数分解的方法快速找到所有可能的乘数组合。
